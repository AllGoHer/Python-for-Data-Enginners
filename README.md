# Python para Ingeniería de Datos

Archivo de códigos de Python, tal y como lo utilizan realmente los ingenieros de datos en su trabajo, el cual va desde los conceptos básicos hasta los patrones listos para producción que se emplean en flujos de trabajo reales.

El presente archivo contiene el siguiente aprendizaje:

• Fundamentos de Python con una perspectiva de ingeniería de datos.

• Estructuras de datos básicas y su comportamiento en flujos de trabajo reales.

• Lectura y escritura de archivos (CSV, JSON, TXT) de forma adecuada.

• Trabajo con conjuntos de datos desordenados y del mundo real.

• Funciones, módulos y estructuración de proyectos.

• Técnicas de gestión de errores, registro de eventos y depuración.

• Escritura de código Python limpio, reutilizable y comprobable.

• Python para la transformación y el análisis de datos.

• Interacción con bases de datos mediante Python.

• Trabajar con API y paginación.

• Python orientado a objetos para el diseño de flujos de trabajo (pipelines).

• Pipelines basados en configuración.

• Consideraciones de rendimiento y optimización.

• Concurrencia, multiprocesamiento y conceptos de escalabilidad.

• Mejores prácticas de producción utilizadas por ingenieros de datos profesionales.

• Cómo encaja Python en Airflow, los flujos de datos y los sistemas reales.
